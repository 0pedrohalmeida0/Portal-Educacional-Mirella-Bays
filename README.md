# ⚠️ PROJETO DESCONTINUADO / ARQUIVADO

### Portal Mirella Bays - Gestão Acadêmica (V1.0)

## 🇺🇸 English Version
This repository contains the legacy version (V1.0) of the Portal Mirella Bays. Originally conceived as my first professional software development experience, it was built to automate the management of active/inactive students and schedule classes.

Today, this version serves as a historical milestone in my portfolio, illustrating my early problem-solving logic and the foundational steps that led to my current expertise in backend frameworks.

Historical Features & Context
Frontend Interface: Structural pages built with HTML5 and styled with CSS3 to create a clear user interface for management.

Cloud Automation (Backend): Logic and API requests processed using Google Apps Script (JavaScript-based) to interact with the frontend.

Database Approach: Utilizing Google Sheets as the initial data repository to store student status and inputs.

The Calendar Challenge (Learning Milestone): This version included a scheduling feature that faced logical conflicts when consuming the Apps Script API. Rather than a failure, this "bug" became the primary catalyst for my transition to robust frameworks (like Django) to handle complex data persistence and backend logic properly.

Technologies Used (V1.0)
Frontend: HTML5 & CSS3

Scripting: Google Apps Script

Data Storage: Google Sheets API

## 🇧🇷 Versão em Português
Este repositório contém a versão legada (V1.0) do Portal Mirella Bays. Originalmente concebido como minha primeira experiência profissional em desenvolvimento de software, o projeto foi construído para automatizar a gestão de alunos (ativos e inativos) e o agendamento de aulas.

Hoje, esta versão serve como um marco histórico no meu portfólio, ilustrando o início da minha lógica de resolução de problemas e os primeiros passos que me levaram a dominar frameworks de backend mais avançados.

Funcionalidades Históricas e Contexto
Interface Frontend: Páginas estruturais construídas com HTML5 e estilizadas com CSS3 para oferecer uma interface de gerenciamento clara ao usuário.

Automação em Nuvem (Backend): Lógica e requisições processadas através do Google Apps Script (baseado em JavaScript) para interagir com a interface.

Banco de Dados: Utilização do Google Sheets como repositório inicial de dados para armazenar os status e cadastros dos alunos.

O Desafio do Calendário (Marco de Aprendizado): Esta versão contava com uma funcionalidade de agendamento que enfrentou conflitos lógicos no consumo da API de scripts. Longe de ser uma falha, esse "bug" foi o principal combustível para a minha transição para frameworks robustos (como o Django), visando resolver de forma definitiva a persistência de dados e a lógica de backend.

Tecnologias Utilizadas (V1.0)
Frontend: HTML5 & CSS3

Scripting: Google Apps Script

Armazenamento: Google Sheets API
